# TernakClouds

TernakClouds is an internal developer platform (IDP) for platform engineering teams. It centralizes deployment, runtime management, access control, secrets, and observability across multiple runtimes.

> The main documentation lives in the `docs/` folder.

## Start here

- `docs/introduction/overview.md`
- `docs/getting-started/installation.md`
- `docs/architecture/overview.md`

## Repository layout

- `backend/` – Go API backend
- `admin/` – Admin dashboard frontend
- `src/` – Public website frontend
- `docs/` – Documentation content
